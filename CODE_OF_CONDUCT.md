#  Code of Conduct

As part of the **Cybersecurity Internship Wiki (Tasks 1–10)**, this project follows a Code of Conduct to ensure a respectful, safe, and collaborative environment for learning and knowledge sharing.

##  Our Commitment
- We commit to creating an environment that is **welcoming, inclusive, and respectful** for everyone.  
- We value **knowledge sharing, constructive feedback, and collaboration**.  
- We encourage a **professional approach** in all interactions.  

##  Standards of Behavior
Participants and contributors are expected to:
- Use **respectful and inclusive language**.  
- Share information responsibly and ethically.  
- Provide **constructive feedback** without personal attacks.  
- Respect different levels of knowledge and experience.  
- Follow **ethical hacking principles** (no unauthorized attacks, scans, or exploitation outside lab environments).  

##  Unacceptable Behavior
The following behaviors will not be tolerated:
- Harassment, hate speech, or personal insults.  
- Sharing malicious code or harmful exploits without context/education.  
- Unauthorized use of knowledge/tools learned from this internship.  
- Plagiarism or misrepresentation of work.  

##  Scope
This Code of Conduct applies to:
- All content in this repository and Wiki.  
- Discussions, pull requests, and comments.  
- Any online or offline interaction related to this project.  

##  Reporting Issues
If you observe behavior that violates this Code of Conduct:
- Report the issue privately to the repository maintainer (**Parmar Rakesh**).  
- Issues will be reviewed respectfully and handled with confidentiality.  

##  Our Values
We believe in:
- **Learn → Apply → Share → Grow**  
- Ethical cybersecurity practices.  
- Building a strong foundation for future professionals.
